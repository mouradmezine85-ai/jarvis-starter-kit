## 7. FAQ (section "FAQ" ou "Collapsible content")

**Titre H2** :
```
Vos questions
```

**Sous-titre arabe** :
```
أسئلتكم
```

### 6 questions-réponses

**Q1 : Combien de temps dure la livraison ?**
R : 48h en moyenne dans les grandes villes, jusqu'à 5 jours pour les wilayas éloignées. Livraison dans les 58 wilayas.

**Q2 : Comment je paie ?**
R : Vous payez à la livraison, en espèces, quand vous recevez votre colis.

**Q3 : Elle convient à quels cheveux ?**
R : Tous types : 160°C pour cheveux fins, 180°C pour cheveux normaux, 200°C pour cheveux épais ou frisés.

**Q4 : Combien de temps dure la batterie ?**
R : Assez pour plusieurs brushings complets. Elle se recharge en USB.

**Q5 : Est-ce que ça abîme les cheveux ?**
R : La céramique MCH répartit la chaleur de façon uniforme et évite les points trop chauds. Utilisez-la sur cheveux secs.

**Q6 : Comment confirmer ma commande ?**
R : Après le formulaire, on vous appelle pour confirmer l'adresse et la date de livraison.
