# Livrables

> Dossier central pour ranger tous les documents, analyses, plans et productions issus de mes sessions avec Claude.

---

## À quoi sert ce dossier

Chaque fois que Claude produit un livrable utile (analyse, stratégie, plan d'action, veille, scraping, etc.), il est rangé ici au lieu de rester dispersé dans Drive, dans la conversation ou dans des exports éphémères.

L'idée : avoir une bibliothèque locale, consultable à tout moment, qui garde la trace de tout ce qui a été produit pour mes activités.

---

## Comment c'est organisé

Les livrables sont rangés par thématique. Voici la structure recommandée (Claude crée les sous-dossiers au fur et à mesure quand c'est nécessaire) :

```
livrables/
├── README.md                       # Ce fichier
├── ets-mezine/
│   ├── strategie-marketing/        # Plans marketing, campagnes, playbooks
│   ├── analyse-marche/             # Études de marché, veille concurrentielle
│   ├── prix-catalogue/             # Scrapings prix, refonte catalogue, packs
│   ├── structuration/              # Méthode de travail, stocks, équipes
│   └── contenus/                   # Scripts vidéo, posts, visuels
├── frimez/
│   └── ...
├── ecommerce/
│   ├── produits-winners/           # Recherche produit, analyses
│   ├── creatives/                  # Visuels, scripts ads
│   └── campagnes/                  # Campagnes Meta, résultats
└── divers/                         # Tout le reste
```

---

## Convention de nommage

Chaque livrable est nommé selon ce format :

```
AAAA-MM-JJ_titre-court.md
```

Exemples :
- `2026-10-06_strategie-marketing-90-jours.md`
- `2026-10-06_veille-comaf-frahtia.md`
- `2026-10-07_playbook-18-campagnes.md`

Les documents très longs peuvent être découpés en plusieurs fichiers numérotés (`01-diagnostic.md`, `02-positionnement.md`, etc.).

---

## Formats acceptés

- **Markdown** (.md) pour les documents texte, c'est le format de base
- **PDF** pour les exports finis à partager
- **CSV / Excel** pour les tableaux de prix, listes de produits, données
- **Images** (jpg, png) pour les visuels, screenshots, mockups

---

## Lien avec Google Drive

Les livrables sont généralement produits en local ici, puis uploadés sur Drive quand ils doivent être partagés. Le lien Drive est mentionné en haut du document pour pouvoir faire l'aller-retour facilement.

Chaque entrée majeure est aussi tracée dans `context/HISTORY.md`.
